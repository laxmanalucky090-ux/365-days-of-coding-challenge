Practice Problem: 169. Majority Element (Easy)

Today I solved LeetCode Problem 169 – Majority Element.
This problem taught me how to think in terms of frequency and smart elimination.

Key learning:
- Majority element means the number that appears more than n/2 times, not the greatest number.
- Using the Boyer–Moore Voting Algorithm, we can find it in O(n) time and O(1) space by canceling out different numbers.

Small steps daily lead to big results.
Consistency matters more than speed.
