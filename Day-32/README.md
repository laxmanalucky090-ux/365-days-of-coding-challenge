Day 32 #365daysofLeetCode – Gas Station (Problem 134)

Today I solved LeetCode Problem 134 – Gas Station.

This problem taught me how to use greedy logic and how to check the feasibility of a solution using total sum.

Key learning:
- If total gas < total cost, we cannot complete the circuit.
- If at any point the tank becomes negative, the starting point must move to the next station.

Small steps daily lead to big results.
Consistency matters more than speed.
